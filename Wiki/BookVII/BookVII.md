# Book VII

D. Joyce's edition: <http://aleph0.clarku.edu/~djoyce/java/elements/bookVII/bookVII.html>

## Definitions

- **[DefVII.1](DefVII.1.md)** — A *unit* is that by virtue of which each of the things that exist is called one.
- **[DefVII.2](DefVII.2.md)** — A *number* is a multitude composed of units.
- **[DefVII.3](DefVII.3.md)** — A number is *a part* of a number, the less of the greater, when it measures the greater;
- **[DefVII.4](DefVII.4.md)** — But *parts* when it does not measure it.
- **[DefVII.5](DefVII.5.md)** — The greater number is a *multiple* of the less when it is measured by the less.
- **[DefVII.6](DefVII.6.md)** — An *even number* is that which is divisible into two equal parts.
- **[DefVII.7](DefVII.7.md)** — An *odd number* is that which is not divisible into two equal parts, or that which differs by a unit from an even number.
- **[DefVII.8](DefVII.8.md)** — An *even-times-even number* is that which is measured by an even number according to an even number.
- **[DefVII.9](DefVII.9.md)** — An *even-times-odd number* is that which is measured by an even number according to an odd number.
- **[DefVII.10](DefVII.10.md)** — An *odd-times-odd number* is that which is measured by an odd number according to an odd number.
- **[DefVII.11](DefVII.11.md)** — A *prime number* is that which is measured by a unit alone.
- **[DefVII.12](DefVII.12.md)** — Numbers *relatively prime* are those which are measured by a unit alone as a common measure.
- **[DefVII.13](DefVII.13.md)** — A *composite number* is that which is measured by some number.
- **[DefVII.14](DefVII.14.md)** — Numbers *relatively composite* are those which are measured by some number as a common measure.
- **[DefVII.15](DefVII.15.md)** — A number is said to *multiply* a number when the latter is added as many times as there are units in the former.
- **[DefVII.16](DefVII.16.md)** — And, when two numbers having multiplied one another make some number, the number so produced be called *plane,* and its *sides* are the numbers which have multiplied one another.
- **[DefVII.17](DefVII.17.md)** — And, when three numbers having multiplied one another make some number, the number so produced be called *solid,* and its *sides* are the numbers which have multiplied one another.
- **[DefVII.18](DefVII.18.md)** — A *square number* is equal multiplied by equal, or a number which is contained by two equal numbers.
- **[DefVII.19](DefVII.19.md)** — And a *cube* is equal multiplied by equal and again by equal, or a number which is contained by three equal numbers.
- **[DefVII.20](DefVII.20.md)** — Numbers are *proportional* when the first is the same multiple, or the same part, or the same parts, of the second that the third is of the fourth.
- **[DefVII.21](DefVII.21.md)** — *Similar plane* and *solid* numbers are those which have their sides proportional.
- **[DefVII.22](DefVII.22.md)** — A *perfect number* is that which is equal to the sum of its own parts.

## Propositions

- **[PropVII.1](PropVII.1.md)** — When two unequal numbers are set out, and the less is continually subtracted in turn from the greater, if the number which is left never measures the one before it until a unit is left, then the original numbers are relatively prime.
- **[PropVII.2](PropVII.2.md)** — To find the greatest common measure of two given numbers not relatively prime.
- **[PropVII.3](PropVII.3.md)** — To find the greatest common measure of three given numbers not relatively prime.
- **[PropVII.4](PropVII.4.md)** — Any number is either a part or parts of any number, the less of the greater.
- **[PropVII.5](PropVII.5.md)** — If a number is part of a number, and another is the same part of another, then the sum is also the same part of the sum that the one is of the one.
- **[PropVII.6](PropVII.6.md)** — If a number is parts of a number, and another is the same parts of another, then the sum is also the same parts of the sum that the one is of the one.
- **[PropVII.7](PropVII.7.md)** — If a number is that part of a number which a subtracted number is of a subtracted number, then the remainder is also the same part of the remainder that the whole is of the whole.
- **[PropVII.8](PropVII.8.md)** — If a number is the same parts of a number that a subtracted number is of a subtracted number, then the remainder is also the same parts of the remainder that the whole is of the whole.
- **[PropVII.9](PropVII.9.md)** — If a number is a part of a number, and another is the same part of another, then alternately, whatever part or parts the first is of the third, the same part, or the same parts, the second is of the fourth.
- **[PropVII.10](PropVII.10.md)** — If a number is parts of a number, and another is the same parts of another, then alternately, whatever part of parts the first is of the third, the same part, or the same parts, the second is of the fourth.
- **[PropVII.11](PropVII.11.md)** — If a whole is to a whole as a subtracted number is to a subtracted number, then the remainder is to the remainder as the whole is to the whole.
- **[PropVII.12](PropVII.12.md)** — If any number of numbers are proportional, then one of the antecedents is to one of the consequents as the sum of the antecedents is to the sum of the consequents.
- **[PropVII.13](PropVII.13.md)** — If four numbers are proportional, then they are also proportional alternately.
- **[PropVII.14](PropVII.14.md)** — If there are any number of numbers, and others equal to them in multitude, which taken two and two together are in the same ratio, then they are also in the same ratio *ex aequali.*
- **[PropVII.15](PropVII.15.md)** — If a unit measures any number, and another number measures any other number the same number of times, then alternately, the unit measures the third number the same number of times that the second measures the fourth.
- **[PropVII.16](PropVII.16.md)** — If two numbers multiplied by one another make certain numbers, then the numbers so produced equal one another.
- **[PropVII.17](PropVII.17.md)** — If a number multiplied by two numbers makes certain numbers, then the numbers so produced have the same ratio as the numbers multiplied.
- **[PropVII.18](PropVII.18.md)** — If two numbers multiplied by any number make certain numbers, then the numbers so produced have the same ratio as the multipliers.
- **[PropVII.19](PropVII.19.md)** — If four numbers are proportional, then the number produced from the first and fourth equals the number produced from the second and third; and, if the number produced from the first and fourth equals that produced from the second and third, then the four numbers are proportional.
- **[PropVII.20](PropVII.20.md)** — The least numbers of those which have the same ratio with them measure those which have the same ratio with them the same number of times; the greater the greater; and the less the less.
- **[PropVII.21](PropVII.21.md)** — Numbers relatively prime are the least of those which have the same ratio with them.
- **[PropVII.22](PropVII.22.md)** — The least numbers of those which have the same ratio with them are relatively prime.
- **[PropVII.23](PropVII.23.md)** — If two numbers are relatively prime, then any number which measures one of them is relatively prime to the remaining number.
- **[PropVII.24](PropVII.24.md)** — If two numbers are relatively prime to any number, then their product is also relatively prime to the same.
- **[PropVII.25](PropVII.25.md)** — If two numbers are relatively prime, then the product of one of them with itself is relatively prime to the remaining one.
- **[PropVII.26](PropVII.26.md)** — If two numbers are relatively prime to two numbers, both to each, then their products are also relatively prime.
- **[PropVII.27](PropVII.27.md)** — If two numbers are relatively prime, and each multiplied by itself makes a certain number, then the products are relatively prime; and, if the original numbers multiplied by the products make certain numbers, then the latter are also relatively prime.
- **[PropVII.28](PropVII.28.md)** — If two numbers are relatively prime, then their sum is also prime to each of them; and, if the sum of two numbers is relatively prime to either of them, then the original numbers are also relatively prime.
- **[PropVII.29](PropVII.29.md)** — Any prime number is relatively prime to any number which it does not measure.
- **[PropVII.30](PropVII.30.md)** — If two numbers, multiplied by one another make some number, and any prime number measures the product, then it also measures one of the original numbers.
- **[PropVII.31](PropVII.31.md)** — Any composite number is measured by some prime number.
- **[PropVII.32](PropVII.32.md)** — Any number is either prime or is measured by some prime number.
- **[PropVII.33](PropVII.33.md)** — Given as many numbers as we please, to find the least of those which have the same ratio with them.
- **[PropVII.34](PropVII.34.md)** — To find the least number which two given numbers measure.
- **[PropVII.35](PropVII.35.md)** — If two numbers measure any number, then the least number measured by them also measures the same.
- **[PropVII.36](PropVII.36.md)** — To find the least number which three given numbers measure.
- **[PropVII.37](PropVII.37.md)** — If a number is measured by any number, then the number which is measured has a part called by the same name as the measuring number.
- **[PropVII.38](PropVII.38.md)** — If a number has any part whatever, then it is measured by a number called by the same name as the part.
- **[PropVII.39](PropVII.39.md)** — To find the number which is the least that has given parts.
