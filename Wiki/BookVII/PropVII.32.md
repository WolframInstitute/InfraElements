# Proposition VII.32

## Statement

Any number is either prime or is measured by some prime
number.

## Proof

Let *A* be a number.

I say that *A* either is prime or is measured by some prime number.

![java applet or image](propVII32.gif)

If now *A* is prime, then that which was proposed is done.

But if it is composite, then some prime number measures it. ([VII.31](PropVII.31.md))

Therefore any number either is prime or is measured by some prime number.

Therefore, *any number is either prime or is measured by some prime
number.*

Q.E.D.

## Guide

After the previous proposition, this one really doesn’t need to be stated at all.
