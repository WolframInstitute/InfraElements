# Definition V.17

## Statement

A ratio *ex aequali* arises when, there being several magnitudes and another set equal to them in multitude which taken two and two are in the same proportion, the first is to the last among the first magnitudes as the first is to the last among the second magnitudes. Or, in other words, it means taking the extreme terms by virtue of the removal of the intermediate terms.

## Guide

*Note: in D. Joyce's edition the Guide is shared with Definition V.17, Definition V.18.*

If *A* : *B* = *D* : *E,* and *B* : *C* = *E* : *F,* then as shown in proposition [V.22](PropV.22.md), *ex aequali, A* : *C* = *D* : *F.* In Book VII ratios of three terms are used in proposition [VI.33](../BookVII/PropVII.33.md). In that proposition, a certain proportion *A* : *B* : *C* = *E* : *F* : *G* is shown. This multiterm proportion may be interpreted as an abbreviation for two proportions *A* : *B* = *E* : *F* and *B* : *C* = *F* : *G.* Then it follows *ex aequali* that *A* : *C* = *E* : *G.* | ![java applet or image](defV17.gif)
However, if *G* : *H* = *M* : *N,* and *H* : *K* = *L* : *M,* then a perturbed proportion holds as shown in proposition [V.23](PropV.23.md), namely, *G* : *K* = *L* : *N.* | ![java applet or image](defV18.gif)
