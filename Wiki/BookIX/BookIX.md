# Book IX

D. Joyce's edition: <http://aleph0.clarku.edu/~djoyce/java/elements/bookIX/bookIX.html>

## Propositions

- **[PropIX.1](PropIX.1.md)** — If two similar plane numbers multiplied by one another make some number, then the product is square.
- **[PropIX.2](PropIX.2.md)** — If two numbers multiplied by one another make a square number, then they are similar plane numbers.
- **[PropIX.3](PropIX.3.md)** — If a cubic number multiplied by itself makes some number, then the product is a cube.
- **[PropIX.4](PropIX.4.md)** — If a cubic number multiplied by a cubic number makes some number, then the product is a cube.
- **[PropIX.5](PropIX.5.md)** — If a cubic number multiplied by any number makes a cubic number, then the multiplied number is also cubic.
- **[PropIX.6](PropIX.6.md)** — If a number multiplied by itself makes a cubic number, then it itself is also cubic.
- **[PropIX.7](PropIX.7.md)** — If a composite number multiplied by any number makes some number, then the product is solid.
- **[PropIX.8](PropIX.8.md)** — If as many numbers as we please beginning from a unit are in continued proportion, then the third from the unit is square as are also those which successively leave out one, the fourth is cubic as are also all those which leave out two, and the seventh is at once cubic and square are also those which leave out five.
- **[PropIX.9](PropIX.9.md)** — If as many numbers as we please beginning from a unit are in continued proportion, and the number after the unit is square, then all the rest are also square; and if the number after the unit is cubic, then all the rest are also cubic.
- **[PropIX.10](PropIX.10.md)** — If as many numbers as we please beginning from a unit are in continued proportion, and the number after the unit is not square, then neither is any other square except the third from the unit and all those which leave out one; and, if the number after the unit is not cubic, then neither is any other cubic except the fourth from the unit and all those which leave out two.
- **[PropIX.11](PropIX.11.md)** — If as many numbers as we please beginning from a unit are in continued proportion, then the less measures the greater according to some one of the numbers which appear among the proportional numbers.
- **[PropIX.12](PropIX.12.md)** — If as many numbers as we please beginning from a unit are in continued proportion, then by whatever prime numbers the last is measured, the next to the unit is also measured by the same.
- **[PropIX.13](PropIX.13.md)** — If as many numbers as we please beginning from a unit are in continued proportion, and the number after the unit is prime, then the greatest is not measured by any except those which have a place among the proportional numbers.
- **[PropIX.14](PropIX.14.md)** — If a number is the least that is measured by prime numbers, then it is not measured by any other prime number except those originally measuring it.
- **[PropIX.15](PropIX.15.md)** — If three numbers in continued proportion are the least of those which have the same ratio with them, then the sum of any two is relatively prime to the remaining number.
- **[PropIX.16](PropIX.16.md)** — If two numbers are relatively prime, then the second is not to any other number as the first is to the second.
- **[PropIX.17](PropIX.17.md)** — If there are as many numbers as we please in continued proportion, and the extremes of them are relatively prime, then the last is not to any other number as the first is to the second.
- **[PropIX.18](PropIX.18.md)** — Given two numbers, to investigate whether it is possible to find a third proportional to them.
- **[PropIX.19](PropIX.19.md)** — Given three numbers, to investigate when it is possible to find a fourth proportional to them.
- **[PropIX.20](PropIX.20.md)** — Prime numbers are more than any assigned multitude of prime numbers.
- **[PropIX.21](PropIX.21.md)** — If as many even numbers as we please are added together, then the sum is even.
- **[PropIX.22](PropIX.22.md)** — If as many odd numbers as we please are added together, and their multitude is even, then the sum is even.
- **[PropIX.23](PropIX.23.md)** — If as many odd numbers as we please are added together, and their multitude is odd, then the sum is also odd.
- **[PropIX.24](PropIX.24.md)** — If an even number is subtracted from an even number, then the remainder is even.
- **[PropIX.25](PropIX.25.md)** — If an odd number is subtracted from an even number, then the remainder is odd.
- **[PropIX.26](PropIX.26.md)** — If an odd number is subtracted from an odd number, then the remainder is even.
- **[PropIX.27](PropIX.27.md)** — If an even number is subtracted from an odd number, then the remainder is odd.
- **[PropIX.28](PropIX.28.md)** — If an odd number is multiplied by an even number, then the product is even.
- **[PropIX.29](PropIX.29.md)** — If an odd number is multiplied by an odd number, then the product is odd.
- **[PropIX.30](PropIX.30.md)** — If an odd number measures an even number, then it also measures half of it.
- **[PropIX.31](PropIX.31.md)** — If an odd number is relatively prime to any number, then it is also relatively prime to double it.
- **[PropIX.32](PropIX.32.md)** — Each of the numbers which are continually doubled beginning from a dyad is even-times-even only.
- **[PropIX.33](PropIX.33.md)** — If a number has its half odd, then it is even-times-odd only.
- **[PropIX.34](PropIX.34.md)** — If an [even] number neither is one of those which is continually doubled from a dyad, nor has its half odd, then it is both even-times-even and even-times-odd.
- **[PropIX.35](PropIX.35.md)** — If as many numbers as we please are in continued proportion, and there is subtracted from the second and the last numbers equal to the first, then the excess of the second is to the first as the excess of the last is to the sum of all those before it.
- **[PropIX.36](PropIX.36.md)** — If as many numbers as we please beginning from a unit are set out continuously in double proportion until the sum of all becomes prime, and if the sum multiplied into the last makes some number, then the product is perfect.
